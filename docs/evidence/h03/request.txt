# 1. OBJETIVO DEL HITO

H03 tiene tres objetivos principales:

**A. Infraestructura de pruebas**

Preparar una infraestructura automatizada, reproducible y mantenible para validar el desarrollo de los siguientes hitos.

**B. Sistema de balance**

Establecer una base de configuración de parámetros de gameplay, separando los valores provisionales de las reglas creativas aprobadas.

**C. Pipeline artístico Modern PSX**

Auditar los assets ya disponibles, verificar su viabilidad técnica y legal, preparar un sistema visual consistente y construir una escena de referencia para comparar materiales, iluminación, texturas y elementos FPS.

No implementar sistemas futuros del videojuego.

H03 debe crear la infraestructura técnica y visual sobre la que trabajará H04.

# 4. DIRECCIÓN ARTÍSTICA OFICIAL

La dirección artística aprobada es:

**MODERN PSX / RETRO INDUSTRIAL CYBERPUNK**

No es una emulación literal del hardware PlayStation 1.

Queremos un FPS moderno con:

- Geometría low-poly.
- Texturas low-resolution.
- Modelos expresivos.
- Tecnología industrial.
- Hardware antiguo.
- Ambientes oscuros.
- Iluminación atmosférica.
- Neones controlados.
- Materiales desgastados.
- Sensación underground.
- Elementos cotidianos retrofuturistas.
- Buena legibilidad moderna.
- Controles y animaciones fluidos.

Prioridades:

1. Identidad visual.
2. Atmósfera.
3. Coherencia.
4. Legibilidad.
5. Siluetas.
6. Rendimiento.
7. Apariencia retro.

No sacrificar el apuntado, el sigilo o la visibilidad de enemigos para emular defectos técnicos antiguos.

No aplicar globalmente efectos extremos de wobble, dithering, pixelación o distorsión.

Todos los efectos potencialmente perjudiciales deben poder desactivarse.

Consulta íntegramente `docs/ART_BIBLE.md` y la decisión D-017, si conserva ese identificador.

Si existen contradicciones documentales, utiliza el registro de decisiones aprobado más reciente y documenta el conflicto.

No inventes nuevas decisiones creativas para resolver ambigüedades importantes.

H03 podrá proponerse para aprobación manual únicamente cuando:

1. La infraestructura de tests funcione de forma reproducible.
2. El ejecutor Windows esté documentado.
3. El sistema de balance provisional sea válido y testeable.
4. La regresión H1 pase.
5. Exista una escena Modern PSX de referencia.
6. Exista una comparación A/B reproducible.
7. Los assets existentes estén inventariados.
8. Los assets experimentales utilizados tengan un estado legal documentado.
9. HomeVideo esté evaluada como fuente.
10. PSXAmmoBoxes esté registrada con su uso ambiental previsto.
11. La Malorian esté clasificada como referencia, no como arma definitiva.
12. Los brazos FPS estén evaluados cuando sea viable.
13. Los resultados gráficos y de rendimiento estén documentados o señalados como pendientes.
14. Los documentos técnicos estén actualizados.
15. No existan errores críticos conocidos sin registrar.
16. El creador disponga de instrucciones para validar manualmente el resultado.

Los requisitos bloqueados deben quedar identificados explícitamente. No ocultar carencias para declarar el hito completado.
