# ALABARDA STUDIOS — GAME VISION
**Versión:** 0.9 (revisión antes de congelar alcance) · 2026-11-20
**Estado:** decisiones creativas aprobadas; balance y producción artística detallada pendientes.

## Fantasía
Boomer shooter FPS 3D para PC/Windows en Godot 4, cyberpunk retro-industrial con rasgos PS1, mercenario cyborg con brazo izquierdo robótico. Contratos de exterminio con rutas tácticas y combate contundente. Dos especializaciones emergentes sin clases: Ninja (movilidad, silencio, precisión) y Tanque (resistencia, potencia); híbridos permitidos.

## Pilares
1. El combate debe ser divertido sin escasez de munición convencional: reserva infinita, cargadores y recargas animadas.
2. Energía recuperada mediante ejecuciones cuerpo a cuerpo, gastada en curación continua o una ultimate equipable.
3. Sigilo completo y reversible: infiltración, detección, combate, ruptura de contacto y búsqueda con memoria.
4. Progresión física y persistente en guarida: comprar, recibir paquete, transportar, montar/instalar, equipar.
5. Estética homogénea a partir de assets gratuitos seleccionados y adaptados; priorizar originalidad en elementos protagonistas.

## Bucle
Guarida → PC (tienda + contratos) → entregas/workbench/árbol de firmware/loadout → contrato Yakuza de tres plantas → boss de dos fases → recompensas/trofeo → guarida. Contrato repetible.
